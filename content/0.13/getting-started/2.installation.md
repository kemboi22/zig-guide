# Installation

Zig ships as a single, statically-linked binary with no external dependencies — no `libc`, no system package manager required.

## Download a release

Grab a prebuilt binary for your platform from the [official downloads page](https://ziglang.org/download/). Extract the archive and add the resulting folder to your `PATH`.

```bash
# Example for Linux x86_64
curl -O https://ziglang.org/download/0.13.0/zig-linux-x86_64-0.13.0.tar.xz
tar -xf zig-linux-x86_64-0.13.0.tar.xz
export PATH="$PWD/zig-linux-x86_64-0.13.0:$PATH"
```

::callout{type="tip"}
Avoid installing Zig through your distro's package manager where possible — versions there are often outdated, and Zig's pre-1.0 API changes quickly between releases.
::

## Verify the install

```bash
zig version
```

This should print `0.13.0` (or whichever version you downloaded).

## Editor support

The [ZLS (Zig Language Server)](https://github.com/zigtools/zls) provides autocomplete, go-to-definition, and inline diagnostics for most editors, including VS Code, Neovim, and Sublime Text.

::callout{type="info"}
Match your ZLS version to your Zig compiler version — mismatches are a common source of confusing language-server errors.
::
