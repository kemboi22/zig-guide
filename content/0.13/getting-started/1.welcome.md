# Welcome

[Zig](https://ziglang.org) is a general-purpose programming language and toolchain for maintaining **robust**, **optimal**, and **reusable** software.

::callout{type="warning"}
The latest release of Zig is 0.13.0 and is currently unstable.
::

To follow this guide, we assume you have:

- Prior experience programming
- Some understanding of low-level programming concepts

Knowing a language like C, C++, Rust, Go, Pascal, or similar will help you follow this guide. You must have an editor, terminal, and internet connection available to you.

## Why Zig?

- **No hidden control flow.** If it's not in the code, it doesn't happen.
- **No hidden allocations.** Memory management is explicit, always.
- **No preprocessor, no macros.** `comptime` replaces both, with real type-checking.
- **First-class C interop.** Zig can import `.h` files directly and link against C libraries without bindings.

::callout{type="tip"}
You can try Zig directly in your browser before installing anything — see the [Installation](/0.13/getting-started/installation) page for links.
::

## What this guide covers

This guide walks through the language from the ground up: variables, control flow, and types, through to the standard library, the build system, and interoperating with C. Each section builds on the last, so it's best read in order if you're new to Zig.
