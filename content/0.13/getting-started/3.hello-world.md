# Hello World

Create a file named `main.zig`:

```zig
const std = @import("std");

pub fn main() void {
    std.debug.print("Hello, world!\n", .{});
}
```

Run it directly with:

```bash
zig run main.zig
```

You should see:

```
Hello, world!
```

## What's happening here

- `@import("std")` pulls in Zig's standard library and binds it to the constant `std`.
- `pub fn main() void` is the entry point — `pub` makes it visible outside the file, and `void` means it returns nothing.
- `std.debug.print` writes formatted output to stderr. The `.{}` is an empty tuple of arguments — there's nothing to interpolate into this format string.

::callout{type="warning"}
`std.debug.print` writes to **stderr**, not stdout, and is intended for debug output. For programs that need to write to stdout, use `std.io.getStdOut().writer()` instead.
::

## Building an executable

`zig run` compiles and runs in one step, but doesn't keep the binary. To produce a standalone executable:

```bash
zig build-exe main.zig
./main
```
