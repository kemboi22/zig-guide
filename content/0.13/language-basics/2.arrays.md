# Arrays

Arrays are denoted by `[N]T`, where `N` is the number of elements and `T` is the element type.

```zig
const a = [5]u8{ 1, 2, 3, 4, 5 };
const b = [_]u8{ 1, 2, 3, 4, 5 }; // length inferred from the literal

const length = a.len; // 5
```

## Multidimensional arrays

Arrays of arrays produce multidimensional structures:

```zig
const matrix = [3][2]i32{
    .{ 1, 2 },
    .{ 3, 4 },
    .{ 5, 6 },
};
```

::callout{type="info"}
Arrays are value types in Zig — assigning or passing one by value copies its full contents. Use a slice (`[]T`) when you want to reference existing data without copying.
::

## Concatenation and repetition

`++` and `**` work on array literals known at compile time:

```zig
const part_one = [_]i32{ 1, 2, 3 };
const part_two = [_]i32{ 4, 5, 6 };
const both = part_one ++ part_two;     // { 1, 2, 3, 4, 5, 6 }
const repeated = part_one ** 2;        // { 1, 2, 3, 1, 2, 3 }
```
