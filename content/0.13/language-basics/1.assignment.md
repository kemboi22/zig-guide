# Assignment

Values are bound with `const` and `var`. The choice is enforced by the compiler, not a style guideline.

```zig
const constant: i32 = 5;  // immutable
var variable: i32 = 5000; // mutable

// @as performs an explicit type coercion
const inferred_constant = @as(i32, 5);
var inferred_variable = @as(i32, 5000);
```

::callout{type="warning"}
Constants and variables **must** have a value. If no known value can be given, `undefined` may be used — but this opts you out of Zig's safety checks for that value.
::

## Type inference

When the right-hand side has an unambiguous type, the type annotation can be dropped:

```zig
const x: u8 = 1;
const y = 1; // y is inferred as comptime_int until used
```

## Unused variables

Zig errors on unused variables and unused constants. Discard a value explicitly with `_`:

```zig
const a = 5;
_ = a; // marks `a` as intentionally unused
```
