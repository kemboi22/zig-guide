# Allocators

Zig has no hidden allocations — anything that needs heap memory takes an `Allocator` explicitly, usually as its first argument.

```zig
const std = @import("std");

pub fn main() !void {
    var gpa = std.heap.GeneralPurposeAllocator(.{}){};
    defer _ = gpa.deinit();
    const allocator = gpa.allocator();

    const memory = try allocator.alloc(u8, 100);
    defer allocator.free(memory);
}
```

::callout{type="tip"}
`defer allocator.free(...)` immediately after allocating is the idiomatic pattern — it keeps the allocation and its matching cleanup visually next to each other.
::

## Common allocators

| Allocator | Use case |
|---|---|
| `GeneralPurposeAllocator` | Safe default; detects leaks and double-frees in debug builds |
| `ArenaAllocator` | Bulk-allocate, free everything at once when done |
| `FixedBufferAllocator` | Allocate from a fixed, pre-existing buffer — no heap involved |
| `page_allocator` | Requests memory directly from the OS, one page at a time |

::callout{type="danger"}
Never use `std.heap.page_allocator` for many small allocations — each request rounds up to a full OS page, wasting memory and time.
::
