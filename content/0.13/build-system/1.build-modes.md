# Build Modes

Zig offers four build modes, each trading compile speed, runtime speed, and safety checks differently.

| Mode | Runtime safety | Speed | Binary size |
|---|---|---|---|
| `Debug` | On | Slow | Large |
| `ReleaseSafe` | On | Fast | Large |
| `ReleaseFast` | Off | Fastest | Medium |
| `ReleaseSmall` | Off | Fast | Small |

```bash
zig build-exe main.zig -O ReleaseSafe
```

::callout{type="tip"}
Ship `ReleaseSafe` by default for most applications — you keep bounds checks and overflow detection, with most of the speed of `ReleaseFast`.
::

::callout{type="warning"}
`ReleaseFast` and `ReleaseSmall` disable safety checks like array bounds checking and integer overflow detection. Undefined behaviour that would `panic` in `Debug` may silently corrupt memory in these modes.
::
