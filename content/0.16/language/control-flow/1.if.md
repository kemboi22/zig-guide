## If Expressions

Zig's `if` accepts only `bool` values — there is no truthy/falsy coercion.

```zig
const std = @import("std");

test "basic if" {
    const a: u32 = 5;
    if (a > 3) {
        // true branch
    }
}
```

`if` is an expression and returns a value:

```zig
const std = @import("std");

test "if as expression" {
    const a: u32 = 5;
    const result = if (a > 3) "big" else "small";
    try std.testing.expectEqualStrings("big", result);
}
```

There is no ternary operator (`a ? b : c`) in Zig — use `if` instead.

## Optional Capture

`if` can capture the payload of an optional:

```zig
const std = @import("std");

test "optional capture" {
    const maybe: ?u32 = 42;
    if (maybe) |value| {
        try std.testing.expectEqual(42, value);
    } else {
        // maybe was null
    }
}
```

## Error Union Capture

`if` can capture the payload or error of an error union:

```zig
const std = @import("std");

fn might_fail(flag: bool) !u32 {
    if (flag) return 42;
    return error.Failed;
}

test "error union capture" {
    if (might_fail(true)) |value| {
        try std.testing.expectEqual(42, value);
    } else |err| {
        // err is the error
    }
}
```

## Capture with Pointer

Use `*` before the capture variable to get a pointer to the payload:

```zig
const std = @import("std");

test "pointer capture" {
    var val: ?u32 = 42;
    if (val) |*ptr| {
        ptr.* += 1;
    }
    try std.testing.expectEqual(43, val.?);
}
```
