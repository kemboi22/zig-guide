## Assignment

Variables can be assigned using the following syntax `(const|var) identifier [:type] = value`.

- `const` indicates that the identifier is immutable meaning it cannot change
- `var` indicates that the variable stores a mutable value that can change.
- `: type` is a type of annotation and it may be ommitted.

###  Zig Types


| Category                 | Syntax                                     | Example                               | Use                              |
| ------------------------ | ------------------------------------------ | ------------------------------------- | -------------------------------- |
| Signed integers          | `i8`, `i16`, `i32`, `i64`, `i128`, `isize` | `var x: i32 = -42;`                   | Store signed whole numbers       |
| Unsigned integers        | `u8`, `u16`, `u32`, `u64`, `u128`, `usize` | `const n: u8 = 255;`                  | Store positive whole numbers     |
| Arbitrary-width integers | `iN`, `uN`                                 | `var flags: u13 = 0;`                 | Packed data and bit manipulation |
| Floating-point           | `f16`, `f32`, `f64`, `f80`, `f128`         | `const pi: f64 = 3.14159;`            | Decimal numbers                  |
| Boolean                  | `bool`                                     | `const ok: bool = true;`              | True/false values                |
| Void                     | `void`                                     | `const nothing: void = {};`           | Represents no value              |
| Never                    | `noreturn`                                 | `fn panic() noreturn {}`              | Functions that never return      |
| Type values              | `type`                                     | `const T: type = i32;`                | Types as values                  |
| Compile-time integer     | `comptime_int`                             | `const x = 42;`                       | Integer literals                 |
| Compile-time float       | `comptime_float`                           | `const y = 3.14;`                     | Float literals                   |
| Any opaque value         | `anyopaque`                                | `*anyopaque`                          | Interoperability with C          |
| Array                    | `[N]T`                                     | `const a: [3]i32 = .{1,2,3};`         | Fixed-size collection            |
| Sentineled array         | `[N:x]T`                                   | `const s: [5:0]u8 = ...;`             | Arrays with sentinel values      |
| Slice                    | `[]T`                                      | `var buf: []u8 = data;`               | Dynamic view into arrays         |
| Constant slice           | `[]const T`                                | `const msg: []const u8 = "Hello";`    | Read-only slices                 |
| Single pointer           | `*T`                                       | `var p: *i32 = &x;`                   | Pointer to one value             |
| Constant pointer         | `*const T`                                 | `const p: *const i32 = &x;`           | Read-only pointer                |
| Many-item pointer        | `[*]T`                                     | `var p: [*]u8 = ptr;`                 | Pointer to multiple items        |
| C pointer                | `[*c]T`                                    | `var p: [*c]u8 = ptr;`                | C interoperability               |
| Sentinel pointer         | `[*:x]T`                                   | `var p: [*:0]u8 = str;`               | Null-terminated buffers          |
| Optional                 | `?T`                                       | `var age: ?u8 = null;`                | Value or `null`                  |
| Error union              | `!T`                                       | `const r: !u32 = 42;`                 | Value or error                   |
| Error set                | `error{...}`                               | `error{NotFound}`                     | Define errors                    |
| Struct                   | `struct { ... }`                           | `const Point = struct {...};`         | Group related fields             |
| Packed struct            | `packed struct { ... }`                    | `const Flags = packed struct {...};`  | Exact bit layout                 |
| Extern struct            | `extern struct { ... }`                    | `const CPoint = extern struct {...};` | C-compatible layout              |
| Enum                     | `enum { ... }`                             | `const Color = enum {...};`           | Named values                     |
| Union                    | `union { ... }`                            | `const Value = union {...};`          | Store one of many types          |
| Tagged union             | `union(enum) { ... }`                      | `const Node = union(enum) {...};`     | Type-safe unions                 |
| Opaque type              | `opaque {}`                                | `const Handle = opaque {};`           | Hide implementation details      |
| Function type            | `fn (...) T`                               | `const F: fn(i32) bool = foo;`        | Function signatures              |
| Vector (SIMD)            | `@Vector(N, T)`                            | `@Vector(4, f32)`                     | SIMD operations                  |
| Tuple                    | `.{ ... }`                                 | `const t = .{1, true};`               | Group heterogeneous values       |
