## Primitive Types

| Type | C Equivalent | Description |
| --- | --- | --- |
| `i8`/`u8` | `int8_t`/`uint8_t` | 8-bit signed/unsigned |
| `i16`/`u16` | `int16_t`/`uint16_t` | 16-bit signed/unsigned |
| `i32`/`u32` | `int32_t`/`uint32_t` | 32-bit signed/unsigned |
| `i64`/`u64` | `int64_t`/`uint64_t` | 64-bit signed/unsigned |
| `i128`/`u128` | `__int128` | 128-bit signed/unsigned |
| `isize`/`usize` | `intptr_t`/`size_t` | Pointer-sized signed/unsigned |
| `f16`/`f32`/`f64`/`f80`/`f128` | IEEE float types | Floating-point |
| `bool` | `bool` | `true` or `false` |
| `void` | (none) | Zero-width type, value is `void{}` |
| `noreturn` | (none) | Type of `break`, `return`, `unreachable` |
| `type` | (none) | The type of types |
| `anyerror` | (none) | Any error code |
| `comptime_int` | (none) | Arbitrary-precision compile-time integer |
| `comptime_float` | (none) | `f128`-precision compile-time float |
| `anyopaque` | `void` | Type-erased pointer |

## C ABI Types

Zig provides C-compatible types for FFI:

| Type | Native Equivalent |
| --- | --- |
| `c_char` | `i8` or `u8` (platform-dependent) |
| `c_short` / `c_ushort` | `i16` / `u16` |
| `c_int` / `c_uint` | `i32` / `u32` |
| `c_long` / `c_ulong` | Platform-dependent |
| `c_longlong` / `c_ulonglong` | `i64` / `u64` |
| `c_longdouble` | `f80` or `f128` |

## Primitive Values

| Value | Type | Description |
| --- | --- | --- |
| `true` / `false` | `bool` | Boolean values |
| `null` | `?T` | Optional null value |
| `undefined` | any type | Unspecified value |
| `{}` | `void` | The only void value |
| `unreachable` | `noreturn` | Marks unreachable code |
