## Integers

Zig's integers are **explicit about size and signedness**. There is no default “just use `int`” — you choose how many bits you need.

| Type | Range (approx.) | Typical use |
| --- | --- | --- |
| `i8` / `u8` | −128…127 / 0…255 | Bytes, ASCII, small counters |
| `i16` / `u16` | ±32K / 0…65K | Short fields, ports |
| `i32` / `u32` | ±2.1B / 0…4.2B | Everyday integers |
| `i64` / `u64` | ±9×10¹⁸ / 0…1.8×10¹⁹ | Large counts, timestamps |
| `i128` / `u128` | Very large | Crypto, big intermediates |
| `isize` / `usize` | Pointer-sized | Indices, lengths, sizes |

You can also invent **arbitrary bit widths**: `u7`, `i13`, `u3`, and so on. That is excellent for packed data and bitfields.

```zig test
const std = @import("std");

test "integer types" {
    const temperature: i32 = -42;
    const byte: u8 = 255;
    const packed_flags: u7 = 100; // only 7 bits wide

    try std.testing.expect(temperature < 0);
    try std.testing.expectEqual(@as(u8, 255), byte);
    try std.testing.expectEqual(@as(u7, 100), packed_flags);
}
```

### Integer literals

Bare number literals have type `comptime_int`. They have arbitrary precision at compile time and coerce into any integer type that can hold them:

```zig test
const std = @import("std");

test "integer literals and bases" {
    const decimal = 255;
    const hex = 0xff;
    const octal = 0o377;
    const binary = 0b1111_1111;
    // Underscores are allowed for readability:
    const million = 1_000_000;

    try std.testing.expectEqual(decimal, hex);
    try std.testing.expectEqual(decimal, octal);
    try std.testing.expectEqual(decimal, binary);
    try std.testing.expectEqual(@as(comptime_int, 1_000_000), million);
}
```

### Integer operators

| Category | Operators |
| --- | --- |
| Arithmetic | `+` `-` `*` `/` `%` |
| Wrapping arithmetic | `+%` `-%` `*%` (wrap on overflow) |
| Saturating arithmetic | `+|` `-|` `*|` (clamp on overflow) |
| Bitwise | `&` `\|` `^` `~` `<<` `>>` |
| Comparison | `==` `!=` `<` `>` `<=` `>=` |

```zig test
const std = @import("std");

test "integer operators" {
    const a: u8 = 10;
    const b: u8 = 3;

    try std.testing.expectEqual(@as(u8, 13), a + b);
    try std.testing.expectEqual(@as(u8, 7), a - b);
    try std.testing.expectEqual(@as(u8, 30), a * b);
    try std.testing.expectEqual(@as(u8, 3), a / b); // truncating division
    try std.testing.expectEqual(@as(u8, 1), a % b);

    // Wrapping: 250 + 10 wraps in u8
    try std.testing.expectEqual(@as(u8, 4), @as(u8, 250) +% 10);
}
```

::callout{type="danger"}
Default `+`, `-`, and `*` are **overflow-checked** in safety builds. Overflow is illegal behaviour, not silent wrap-around. Use `+%` / `-%` / `*%` when wrap is intentional, or larger types when you need headroom.
::

### `usize` and indexing

Array lengths, slice lengths, and indices are almost always `usize` (unsigned, pointer-sized). Prefer it for anything that describes memory layout or positions in a collection.

## Floating-point

Zig supports IEEE-754 floats at several precisions:

| Type | Mantissa bits | Notes |
| --- | --- | --- |
| `f16` | 10 | Half precision, compact storage |
| `f32` | 23 | Single precision |
| `f64` | 52 | Double precision (most common) |
| `f80` | 64 | x87 extended (platform-specific) |
| `f128` | 112 | Quad precision |

```zig test
const std = @import("std");

test "floats" {
    const pi: f64 = 3.14159;
    const electron_mass: f32 = 9.109e-31;
    const half: f16 = 0.5;

    try std.testing.expect(pi > 3.0);
    try std.testing.expect(electron_mass > 0);
    try std.testing.expectEqual(@as(f16, 0.5), half);
}
```

Float literals are `comptime_float` (computed at `f128` precision) and coerce into any float type. Smaller floats also coerce to larger ones: `f16` → `f32` → `f64` → `f128`.

::callout{type="warning"}
Never compare floats with raw `==` when rounding error matters. Prefer an epsilon check, or better, design so you do not need exact equality.
::

## Bool

`bool` has exactly two values: `true` and `false`. It is one byte wide. There is **no** truthy/falsy coercion — you cannot write `if (pointer)` or `if (count)`; you must produce a real `bool`.

```zig test
const std = @import("std");

test "bool and logic" {
    const ready: bool = true;
    const done: bool = false;

    try std.testing.expect(ready and !done);
    try std.testing.expect(ready or done);
    try std.testing.expect(!(ready and done));
}
```

| Operator | Meaning | Short-circuits? |
| --- | --- | --- |
| `a and b` | Logical AND | Yes |
| `a or b` | Logical OR | Yes |
| `!a` | Logical NOT | — |

Because `and` / `or` short-circuit, the right-hand side is only evaluated when needed — same idea as `&&` / `||` in C-family languages, but with English keywords.

## Zero values

Every type in Zig has a well-defined **zero value**. That is what you get from `std.mem.zeroes(T)`, from many default initializations, and conceptually when memory is fully zeroed:

| Type | Zero value |
| --- | --- |
| Integers | `0` |
| Floats | `0.0` |
| `bool` | `false` |
| `void` | `{}` |
| Arrays / structs | Each element / field zeroed |
| Optionals (`?T`) | `null` |
| Pointers (as optional) | `null` |

```zig test
const std = @import("std");

test "zero values" {
    const z_int: i32 = 0;
    const z_bool: bool = false;
    const z_void: void = {};
    const z_opt: ?u32 = null;

    try std.testing.expectEqual(@as(i32, 0), z_int);
    try std.testing.expect(!z_bool);
    try std.testing.expect(z_opt == null);
    _ = z_void;
}
```

Contrast that with `undefined`:

```zig
var scratch: i32 = undefined; // not zero — unknown bits until you write
```

| | Zero value | `undefined` |
| --- | --- | --- |
| Safe to read? | Yes | No (illegal behaviour) |
| Meaning | Known default | “I will write before I read” |
| Typical use | Defaults, clearing buffers | Avoiding a fake initial value you never use |

::callout{type="tip"}
When in doubt, initialize with a real zero or a meaningful default. Reach for `undefined` only when you will fill every byte before any read — for example, a buffer you pass to a read syscall that overwrites it completely.
::

## Putting it together

```zig test
const std = @import("std");

test "mixed primitives" {
    var hits: u32 = 0;
    const threshold: f64 = 0.75;
    const enabled: bool = true;

    if (enabled) hits += 1;

    const ratio: f64 = @as(f64, @floatFromInt(hits)) / 10.0;
    try std.testing.expect(ratio < threshold);
}
```
