## Integers

Zig provides signed (`i`) and unsigned (`u`) integer types with explicit bit widths:

| Type | Range | Use Case |
| --- | --- | --- |
| `i8` / `u8` | -128..127 / 0..255 | Bytes, small counters |
| `i16` / `u16` | ±32,768 / 0..65,535 | Short values |
| `i32` / `u32` | ±2.1B / 0..4.2B | Standard integers |
| `i64` / `u64` | ±9.2E18 / 0..1.8E19 | Large values |
| `i128` / `u128` | Arbitrary large | Big numbers |
| `isize` / `usize` | Pointer-sized | Indices, sizes |

You can also use arbitrary bit widths: `u7`, `i13`, etc.

```zig
const a: i32 = -42;
const b: u8 = 255;
const c: u7 = 100; // 7-bit unsigned
```

Integer literals have the type `comptime_int` and coerce to any integer type that can hold their value.

## Floating-Point

Zig supports IEEE-754 floating-point types:

| Type | Precision | Description |
| --- | --- | --- |
| `f16` | 10-bit mantissa | Half-precision |
| `f32` | 23-bit mantissa | Single-precision |
| `f64` | 52-bit mantissa | Double-precision |
| `f80` | 64-bit mantissa | x87 extended |
| `f128` | 112-bit mantissa | Quad-precision |

```zig
const pi: f64 = 3.14159;
const mass: f32 = 1.67e-27;
```

Float literals are `comptime_float` (internally `f128` precision) and coerce to any float type.

Floats coerce to larger float types automatically: `f16` -> `f32` -> `f64` -> `f128`.

## Bool

The `bool` type has two values: `true` and `false`. It is 1 byte wide.

```zig
const is_ready: bool = true;
const is_done: bool = false;
```

Boolean operators:
- `a and b` — logical AND (short-circuit)
- `a or b` — logical OR (short-circuit)
- `!a` — logical NOT

## Zero Values

Every type in Zig has a known zero/default value:

| Type | Zero Value |
| --- | --- |
| Integer types | `0` |
| Float types | `0.0` |
| `bool` | `false` |
| `void` | `{}` |
| Arrays | Each element zeroed |
| Pointers | `null` (as optional) |
| Structs | Each field zeroed |

Use `undefined` to explicitly leave a value uninitialized:

```zig
var x: i32 = undefined; // uninitialized, must be set before use
```

Accessing an `undefined` value without first assigning it is detectable illegal behaviour.
