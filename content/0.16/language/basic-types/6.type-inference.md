## `const` Type Inference

When declaring a `const` without an explicit type, Zig infers the type from the value:

```zig
const a = 42;
// @TypeOf(a) == comptime_int

const b = 3.14;
// @TypeOf(b) == comptime_float

const c = true;
// @TypeOf(c) == bool

const d = "hello";
// @TypeOf(d) == *const [5:0]u8
```

Integer literals become `comptime_int`, which has arbitrary precision and coerces to any runtime integer type as needed.

## `var` Type Inference

`var` declarations also support inference, but the value must have a concrete runtime type:

```zig
var x: u32 = 42; // explicit type required for runtime vars
```

Integer literals assigned to `var` without a type annotation will cause a compile error because `comptime_int` cannot be used at runtime:

```zig
var x = 42; // COMPILE ERROR: cannot store runtime value in type 'comptime_int'
```

## `@TypeOf`

Use the builtin `@TypeOf` to inspect inferred types at compile time:

```zig
const T = @TypeOf(42);
// T == comptime_int
```

## Contextual Inference

Zig also infers types from context — how a value is used:

```zig
const std = @import("std");

test "contextual inference" {
    const x: u64 = 42; // explicit annotation narrows comptime_int -> u64
    const y = x + 10;  // y is inferred as u64 (peer type with x)
    try std.testing.expect(y == 52);
}
```

Peer type resolution finds a common type across branches:

```zig
const val = if (flag) @as(u32, 1) else @as(u32, 2);
// val is u32
```

If types conflict without annotation, a compile error occurs:

```zig
// COMPILE ERROR: peer type resolution failed
const val = if (flag) @as(u32, 1) else @as(i32, -1);
```

## `comptime` Inference

Variables tagged `comptime` are guaranteed to be evaluated at compile time:

```zig
comptime {
    const x = 42; // comptime_int
    const y = x + 1; // comptime_int
}
```

Function parameters can also be tagged `comptime`, enabling compile-time polymorphism:

```zig
fn Matrix(comptime T: type, comptime rows: u32, comptime cols: u32) type {
    return [rows][cols]T;
}

const Mat4x4 = Matrix(f32, 4, 4);
// Mat4x4 == [4][4]f32
```
