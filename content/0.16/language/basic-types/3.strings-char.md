## Strings

String literals in Zig are `*const [N:0]u8` — a single-item pointer to a null-terminated array of bytes.

```zig
const greeting = "hello";
// @TypeOf(greeting) == *const [5:0]u8
```

They coerce to `[]const u8` (a slice), which is the idiomatic way to work with strings:

```zig
const msg: []const u8 = "hello";
```

Because Zig source is UTF-8 encoded, non-ASCII bytes in string literals are preserved as-is:

```zig
const unicode = "⚡ zig ⚡";
```

Use `\xNN` to embed arbitrary bytes:

```zig
const raw = "\xff\xfe"; // non-UTF-8 bytes
```

Available escape sequences:

| Escape | Meaning |
| --- | --- |
| `\n` | Newline |
| `\r` | Carriage return |
| `\t` | Tab |
| `\\` | Backslash |
| `\'` | Single quote |
| `\"` | Double quote |
| `\xNN` | Hex byte value |
| `\u{NNNN}` | Unicode code point |

## Character Literals

Character literals use single quotes and have type `comptime_int` (the same as integer literals):

```zig
const c = 'z';
// @TypeOf(c) == comptime_int
const newline = '\n';
const hex = '\x65'; // 'e'
const unicode_char = '\u{1f4a9}';
const emoji = '💯';
```

Character literals are Unicode code points (`u21` range). They coerce to any integer type that can hold their value.

## Working with Strings

The standard library provides `std.mem` for common string operations:

```zig
const std = @import("std");
const mem = std.mem;

test "string equality" {
    const a: []const u8 = "hello";
    const b: []const u8 = "world";
    try mem.eql(u8, a, "hello"); // true
}
```

Key types for string work:
- `[]const u8` — read-only string slice (most common)
- `[]u8` — mutable byte slice
- `[:0]const u8` — sentinel-terminated (null-terminated) string slice
- `*const [N:0]u8` — string literal type
