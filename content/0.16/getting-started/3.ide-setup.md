# IDE Setup

All major text editors have syntax highlighting support for Zig. Some bundle it out of the box, while others require installing a plugin.

If you’re interested in deeper editor integration, check out [zigtools/zls](https://github.com/zigtools/zls), the official Zig Language Server. For a broader list of community tools, see the [Tools](https://ziglang.org/learn/tools/) section on the Zig website.

## Visual Studio Code

Install the official [Zig extension](https://marketplace.visualstudio.com/items?itemName=ziglang.vscode-zig) from the marketplace. It bundles syntax highlighting and ZLS support.

## Neovim

You can use ZLS with `nvim-lspconfig`:

```lua
require('lspconfig').zls.setup({})
```

Treesitter support is available through `nvim-treesitter`.

## Vim

For Vim, use a plugin manager to install a Zig syntax plugin, such as:

```bash
git clone https://github.com/ziglang/zig.vim ~/.vim/pack/plugins/start/zig.vim
```

ZLS can be configured with `vim-lsp` or `coc.nvim`.

## Emacs

Install `zig-mode` from MELPA, then enable ZLS with `eglot` or `lsp-mode`:

```elisp
(use-package zig-mode)
(use-package lsp-mode
  :hook (zig-mode . lsp))
```

## Sublime Text

The [Zig package](https://packagecontrol.io/packages/Zig%20Language) on Package Control provides syntax highlighting.

## LSP Configuration

ZLS is distributed separately. Once installed, most editors will automatically start it when you open a `.zig` file. You can configure ZLS through a `zls.json` file in your project root or via your editor settings.
