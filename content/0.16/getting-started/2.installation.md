# Installation

## Linux

Zig is also present in many package managers

### Arch Linux 

```bash
sudo pacman -S zig
```

### Debian / Ubuntu

```bash
sudo apt install zig
```

### Fedora

```bash
sudo dnf install zig
```

### Alpine Linux 

```bash
sudo apk add zig
```

### OpenSUSE

```bash
sudo zypper install zig
```

### Gentoo

```bash
sudo emerge --ask dev-lang/zig
```

### Installing Manually

1. [Download](https://ziglang.org/download/#release-0.16.0) a prebuilt version of zig.
    Choose a build of Zig 0.16 for Linux that matches your CPU architecture. If you're unsure which architecture you're using, this can be found with:
    ```bash
    uname -m
    ```
2. Extract the archive using tar, e.g.
    ```bash
    tar xf zig-linux-x86_64-0.16.0.tar.xz
    ```
3. Add the location of your Zig binary to your path, e.g.
    ```bash
    echo 'export PATH="$HOME/zig-linux-x86_64-0.16.0:$PATH"' >> ~/.bashrc
    ```

### Direct Download

This is the most straight-forward way of obtaining Zig: grab a Zig bundle for your platform from the [Downloads](https://ziglang.org/download/) page, extract it in a directory and add it to your PATH to be able to call zig from any location.

#### Setting up PATH on Windows

To setup your path on Windows run one of the following snippets of code in a Powershell instance. Choose if you want to apply this change on a system-wide level (requires running Powershell with admin privileges) or just for your user, and make sure to change the snippet to point at the location where your copy of Zig lies. The ; before C: is not a typo.

System wide (admin Powershell):

```powershell
[Environment]::SetEnvironmentVariable(
   "Path",
   [Environment]::GetEnvironmentVariable("Path", "Machine") + ";C:\your-path\zig-windows-x86_64-your-version",
   "Machine"
)
```

User level (Powershell):

```powershell
[Environment]::SetEnvironmentVariable(
   "Path",
   [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\your-path\zig-windows-x86_64-your-version",
   "User"
)
```
After you’re done, restart your Powershell instance.
