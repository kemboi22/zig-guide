# What's new in Zig 0.13.0

Every Zig release brings breaking changes — that's expected pre-1.0 — but 0.13.0 also brings real quality-of-life wins for everyday development.

## Faster incremental compilation

The self-hosted x86_64 backend continues to mature, cutting incremental build times significantly for many projects compared to the LLVM backend.

## Package manager improvements

`build.zig.zon` gained clearer error messages for hash mismatches, making it easier to diagnose a stale lockfile versus a genuinely tampered dependency.

::callout{type="info"}
If you maintain a package, re-run `zig fetch --save` after upgrading to regenerate hashes in the new format.
::
